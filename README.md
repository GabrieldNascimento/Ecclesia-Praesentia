# Ecclesia Frontend

Frontend da plataforma Ecclesia, desenvolvido para a visualização de eventos religiosos e demonstração de funcionalidades relacionadas a contribuições e doações de fiéis.

## Funcionalidades

- Visualização de eventos da igreja
- Consulta de informações dos eventos
- Simulação de fluxo de doações
- Integração com Web API REST

## Tecnologias Utilizadas

- React
- Vite
- JavaScript
- HTML5
- CSS3
